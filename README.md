¡Holiiii! 👋 Bienvenidx a **Mis Tareas** 🌸, una app súper linda, moderna y funcional pensada para organizar tu día a día, registrar usuarios y llevar el control de todo lo que tenés por hacer en un solo lugar 📋✨.

---

## 🎨 𝓠𝓾é 𝓹𝓾𝓮𝓭𝓮𝓼 𝓱𝓪𝓬𝓮𝓻 𝓬𝓸𝓷 𝓮𝓼𝓽𝓪 𝓐𝓹𝓹 ✨

- 🔐 **Registro de usuarios:** Podés registrarte con tu nombre, email y contraseña 💌.
- 👤 **Creador visible:** Cada tarea muestra exactamente **quién la creó** 🏷️✨.
- 📝 **Gestión total (CRUD):**
  - ➕ Agregar nuevas tareas en segundos ⚡.
  - 🔘 Marcar como completadas con un suave texto tachado ✏️.
  - 🗑️ Eliminar las tareas que ya no necesites.
- 📊 **Barra de progreso interactiva:** Mirá cómo sube el porcentaje a medida que vas completando tus metas 📈💖.
- 💾 **Persistencia local:** ¡No te preocupes por reiniciar la página! Todo se guarda mágicamente en tu navegador con `localStorage` 🔮.
- 🌙 **Diseño Dark Mode:** Una interfaz hermosa en tonos oscuros con Tailwind CSS para cuidar tu vista 🌌✨.
